# Student Registration Form

## Aim
To develop a student registration form using Java Swing.

## Features
- Enter student details such as name, roll number, and branch
- Select gender and accept terms
- Basic validation, submit, and reset controls

## Technologies
Java, Swing, event handling.

## How to Run
Open a terminal in this folder and run:

```bash
javac aniket.java
java aniket
```

If the main class or file name has changed, use the correct name from the source code.
