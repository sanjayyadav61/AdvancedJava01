Viva Questions Q. Whatis a Servlet? Ans. A Java server-side class managed by a Servlet container to process requests and generate responses. Q. Whatis a Servlet Container? Ans. A runtime environment that manages Servlet lifecycle and request processing. Q. Whatis Tomcat? Ans. A web server and Servlet container used to run Java web applications. Q. Whatis HttpServlet? Ans. A base class commonly extended to create HTTP Servlets. Q. Whatis @WebServlet? Ans. An annotation used to map a Servlet to a URL pattern. Q. Whatis doGet()? Ans. It handles HTTP GET requests. Q. Whatis doPost()? Ans. It handles HTTP POST requests. Q. Whatis Servlet lifecycle? Ans. Loading/creation, initialization, request processing and destruction managed by the container. Q. Whatis ServletConfig? Ans. Configuration information specific to one Servlet. Q. Whatis ServletContext? Ans. Context representing the entire web application. Q. Whatis HttpServletRequest?Ans. Object representing the incoming client request. Q. Whatis HttpServletResponse? Ans. Object used to construct the server response. Q. Whyis session tracking needed? Ans. HTTP is stateless, so session mechanisms associate multiple requests with a user/session. Q. Whatis HttpSession? Ans. A server-side mechanism for storing session-associated information. Q. Whatis a Cookie? Ans. A small client-associated value sent according to cookie rules. Q. Whatis a Listener? Ans. A component that receives notifications about specified application or session events. Q. Whatis a Filter? Ans. A component that intercepts requests/responses around a target resource. Q. Whyis chain.doFilter() used? Ans. To pass processing to the next component in the filter chain. Q. Which package is used with Tomcat 11? Ans. jakarta.servlet and jakarta.servlet.http. 40.
